🎬 Каталог фильмов – Multi‑Language Implementation
Тестовый репозиторий с реализацией консольного каталога фильмов на 7 языках программирования.
Приложение позволяет вести личную коллекцию фильмов: добавлять, редактировать, удалять, искать, отмечать просмотренными, ставить оценки и получать статистику.

🍿 Что такое Каталог фильмов?
Это простой, но мощный инструмент для учёта просмотренных и запланированных к просмотру фильмов. Вы можете хранить информацию о каждом фильме: название, режиссёр, год выпуска, жанр, статус (просмотрен или нет), вашу оценку (от 1 до 10). Приложение предоставляет:

Добавление фильмов с указанием всех полей.

Просмотр всего списка или фильтрация по жанру, статусу, году.

Поиск по названию или режиссёру (частичное совпадение).

Отметка просмотра – переключение статуса.

Редактирование и удаление записей.

Статистика: общее количество, просмотренные/непросмотренные, средняя оценка, распределение по жанрам.

Сохранение и загрузка данных в формате JSON для постоянного хранения.

Удобное меню с подсказками, валидация ввода.

✨ Особенности
Интерактивное меню с выбором действий.

Все поля валидируются (год от 1900 до текущего, оценка 1–10).

Автоматическая генерация ID и даты добавления.

Фильтрация по нескольким критериям.

Расширенная статистика: средняя оценка только для просмотренных фильмов, топ-жанры.

Данные хранятся в формате JSON – легко читаемо и переносимо.

Цветной вывод (где поддерживается) для наглядности.

Загрузка данных при старте.
